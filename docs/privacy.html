Privacy

Certificate Utility is designed so that sensitive PKI material never leaves your machine.

What stays local

Certificate parsing, key and certificate generation, PKCS#12/PKCS#7 handling, chain verification and private-key matching all run inside the local or remote VS Code extension host. The extension does not upload certificate contents, private keys or scan results, and it does not collect analytics or telemetry.

Network connections you control

  • Remote inspection connects to the host and port you enter.
  • Revocation checks contact the CRL and OCSP endpoints named in the certificate you are validating.
  • Remote watchlist connects to the endpoints you configure in certificateUtil.remoteWatchlist.

No other outbound connections are made by the extension.

External tools

OpenSSL and Java keytool operations, when used, run on the extension host machine using the executables you have installed.

This website

This site is static. It sets no cookies and has no analytics. Your light/dark preference is stored only in your browser’s local storage.
